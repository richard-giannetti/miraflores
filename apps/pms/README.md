# apps/pms — property management system

Reserved for step 2. Owner back-office for both villas: calendar synced with Airbnb (iCal),
bookings, guests, online check-in (ID documents for Spanish guest registration, replacing the old
WordPress `/checking` form), cleaning, income. Later feeds availability to `apps/web` for direct bookings.
Stack chosen at the start of step 2 — see [architecture](../../docs/architecture.md).
